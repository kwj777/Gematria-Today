Forum Reputation Scale

Use this as a baseline for tier thresholds, progression, and moderation workflow decisions.

Reputation bands

Reputation Tier name
< 0 Restricted
0–24 Newcomer
25–99 Contributor
100–249 Regular
250–499 Trusted
500–999 Senior
1000+ Steward

Scoring inputs

  • +10: Post marked as helpful/solution.
  • +5: Upvote on a post or comment.
  • +3: Accurate content flag that leads to moderator action.
  • +2: Daily login streak bonus (once per day).
  • -2: Downvote received.
  • -10: Confirmed rule violation.
  • -25: Severe abuse event (spam, harassment, hate content).
