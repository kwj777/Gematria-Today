Name analysis

Use one stable name format, compare against related terms, and validate values with results clusters before interpretation.

Step A: Format the full name consistently

  • Pick one exact spelling and spacing style for the full name.
  • Do not switch between initials and full words in the same set.
  • Keep suffixes/titles out unless they are part of your core hypothesis.

Step B: Run name and comparison checks

Calculate the name, then compare it with related phrase groups from the same theme to avoid single-hit conclusions.
