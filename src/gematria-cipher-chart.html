Which cipher this site’s calculator uses

The main calculator, the name calculator, the Bible names list and every /v/ and /w/ page on Gematria.Today use one cipher: English Sumerian, which this site also calls English Gematria or English Base-{{ F.sumerianFactor }}. Each letter is worth its alphabet position times {{ F.sumerianFactor }}, so A = {{ sum.first }}, B = {{ sum.values[1].value }} and Z = {{ sum.last }}. In the multi-cipher calculator it is the row labelled Sumerian, and the site’s build checks that column against the main calculator’s letter values, one letter at a time.

Two consequences follow from the ×{{ F.sumerianFactor }}. Every total is a multiple of {{ F.sumerianFactor }}, so a word’s digital root can only be {{ F.siteDigitalRoots }}. And every total is exactly {{ F.sumerianFactor }} times the word’s English Ordinal total, so the two ciphers always find the same matches, on a larger scale: {{ ex.word }} is {{ ex.siteTotal }} here and {{ ex.total['english-ordinal'] }} in English Ordinal. Why this site uses English gematria explains the choice and what it does and doesn’t let you claim.

Each cipher, one chart at a time

Calculators do not agree on names. The same table can appear under different labels, and the same label can mean different tables, so identify a cipher by its letter values rather than its name. Each cipher below links to the matching post in the English Gematria Cipher Atlas, a blog series on where these ciphers come from and when they are worth using.

English Ordinal gematria (A = {{ ord.first }} to Z = {{ ord.last }})

Each letter is worth its position in the alphabet. Also called Simple Ordinal or just Ordinal, it is the baseline most of the other tables are built from: Reverse Ordinal mirrors it, Full Reduction shrinks it to single digits (and Reverse Full Reduction does the same to Reverse Ordinal), and Sumerian multiplies it. Because of that, it is the most useful total to report beside a match in any other cipher.

Reverse Ordinal gematria (A = {{ rev.first }} to Z = {{ rev.last }})

The alphabet counted backwards. A letter’s Ordinal and Reverse Ordinal values always add to {{ F.mirrorTotal }} (M is {{ ord.values[12].value }} and {{ rev.values[12].value }}), so a word’s Reverse Ordinal total is {{ F.mirrorTotal }} times its letter count minus its Ordinal total. Two words of the same length that match in one cipher therefore match in the other. It reverses the alphabet, not the word, and it adds no information that the Ordinal total and the letter count don’t already hold.

Full Reduction, or Pythagorean gematria ({{ red.min }} to {{ red.max }})

Each Ordinal value is reduced to a single digit, so the alphabet runs from {{ red.min }} to {{ red.max }} and starts again: {{ F.reductionOnes }} are all {{ red.min }}, and {{ F.reductionNines }} are both {{ red.max }}. The last run stops one short, at Z = {{ F.reductionZ }}. With only {{ red.distinctValues }} values shared among {{ F.letterCount }} letters, short words collide often. A word’s Full Reduction total always has the same digital root as its English Ordinal total, but it depends on which letters the word contains: {{ twins.first }} and {{ twins.second }} are both {{ twins.ordinal }} in English Ordinal, and {{ twins.firstReduction }} and {{ twins.secondReduction }} here. The “Pythagorean” label borrows an old name; the table itself is a modern English one.

Reverse Full Reduction (A = {{ rred.first }} to Z = {{ rred.last }})

The Reverse Ordinal values reduced to single digits: A is {{ rred.first }} because its Reverse Ordinal value, {{ rev.first }}, reduces to {{ rred.first }}. A letter’s two reduced values add to {{ F.reductionPairTotal }}, except {{ F.reductionPairExceptions }}, which are {{ F.reverseReductionTop }} in both ciphers. So each digit from {{ F.reverseReductionLowerFirst }} to {{ F.reverseReductionLowerLast }} stands for {{ F.reverseReductionLowerCountWord }} letters, and {{ F.reverseReductionTop }} for only {{ F.reverseReductionTopCountWord }}. It is easy to miscount by hand, because its values run against the alphabet, so check a total against this chart or the calculator before you rely on it.

Sumerian gematria chart (A = {{ sum.first }} to Z = {{ sum.last }})

English Ordinal multiplied by {{ F.sumerianFactor }}, and the cipher this site’s calculator uses. The multiplication changes the size of every total but not which words match: two words that agree here agree in English Ordinal, and the other way round. The name is modern branding rather than history; the Sumerians did not write with an alphabet, let alone the English one. Because every total is exactly {{ F.sumerianFactor }} times the English Ordinal total, a word reaches 666 in this cipher exactly when its English Ordinal total is {{ F.ordinalFor666 }}. The 666 in gematria page looks at that number in more detail.

Reverse Sumerian (A = {{ rsum.first }} to Z = {{ rsum.last }})

Reverse Ordinal multiplied by {{ F.reverseSumerianFactor }}. It stands to Sumerian as Reverse Ordinal stands to English Ordinal: a letter’s Sumerian and Reverse Sumerian values always add to {{ F.sumerianMirrorTotal }}, so it holds nothing that the Sumerian total and the letter count don’t. The Cipher Atlas has no post of its own on it; its Sumerian post explains the ×{{ F.reverseSumerianFactor }} scaling the two share, and why scaling adds no information.

Jewish / Latin ({% for band in F.jewishLatinBands %}{{ band.low }}–{{ band.high }}{% if not loop.last %}, {% endif %}{% endfor %})

This table borrows the shape of the Hebrew numerals: {% for band in F.jewishLatinBands %}{{ band.from }} to {{ band.to }} count {{ band.low }} to {{ band.high }}{% if loop.index == 1 %}, {% elif not loop.last %} and {% endif %}{% endfor %}. Because each band is ten times the last, the end of the alphabet dominates: S alone ({{ F.jewishLatinS }}) outweighs A to I together ({{ F.jewishLatinAtoI }}), and Z ({{ F.jewishLatinZ }}) outweighs A to R together ({{ F.jewishLatinAtoR }}). Like the two reductions, its total cannot be worked out from the English Ordinal total, though the two always share a digital root. Despite the name, it is an English table modelled on Hebrew numerals, not a traditional Jewish method; the Hebrew gematria chart shows the system it imitates. The name is not settled either: some calculators call this table English Extended, and some use the name Jewish for a different table, which gives J, V and W the three largest values and every other letter from K onwards a smaller one than here. Check the letter values before you compare totals from two calculators.

How the ciphers relate, and why it matters for matches

The {{ F.cipherCountWord }} ciphers are not {{ F.cipherCountWord }} independent tests. They fall into three groups:

  • The Ordinal family: English Ordinal, Reverse Ordinal, Sumerian and Reverse Sumerian. Given any one of these totals and the number of letters, the other three follow.
    • {%- set frl = F.fullReductionLoss %} {%- set rfrl = F.reverseReductionLoss %}
  • The reductions: Full Reduction and Reverse Full Reduction. Each depends on exactly which letters a word contains, but keeps the digital root of the cipher it reduces. Full Reduction is the English Ordinal total minus {{ frl.small.loss }} for each letter from {{ frl.small.from }} to {{ frl.small.to }} and {{ frl.large.loss }} for each from {{ frl.large.from }} to {{ frl.large.to }}; Reverse Full Reduction is the Reverse Ordinal total minus {{ rfrl.small.loss }} for each letter from {{ rfrl.small.from }} to {{ rfrl.small.to }} and {{ rfrl.large.loss }} for each from {{ rfrl.large.from }} to {{ rfrl.large.to }}. So two words level in the unreduced cipher also match in its reduction whenever they lose the same amount.
  • Jewish / Latin, which also depends on the exact letters, and also keeps English Ordinal’s digital root.

Quick answers

What is a gematria cipher chart?
A table of what each letter is worth in one or more ciphers. To find a word’s value, look up each of its letters in one column and add them.
What is the Jewish / Latin cipher?
An English table modelled on Hebrew numerals: {% for band in F.jewishLatinBands %}{{ band.from }} to {{ band.to }} count {{ band.low }} to {{ band.high }}{% if loop.index == 1 %}, {% elif not loop.last %} and {% endif %}{% endfor %}. Some calculators give the name Jewish to a different table, so compare the letter values, not the name, before you compare totals. The Jewish / Latin chart above lists every letter.
What is English Ordinal gematria?
The simplest English cipher: A = {{ ord.first }}, B = {{ ord.values[1].value }} … Z = {{ ord.last }}, each letter’s position in the alphabet. Sumerian is English Ordinal times {{ F.sumerianFactor }}, so the two always agree on which words match.
How does Reverse Ordinal gematria work?
It numbers the alphabet backwards, from A = {{ rev.first }} to Z = {{ rev.last }}. A letter’s Ordinal and Reverse Ordinal values always add to {{ F.mirrorTotal }}, so a word’s Reverse Ordinal total is {{ F.mirrorTotal }} times its letter count minus its Ordinal total.
Why do two gematria calculators give different totals for the same word?
Usually because they are using different ciphers, or different tables under the same cipher name. Match the letter values against this chart rather than trusting the label, name the cipher next to every value you quote, and choose it before you look at results. No cipher turns gematria into a way to predict or prove anything; see the disclaimer.
